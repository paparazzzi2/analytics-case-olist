## 1. Цель

Ежедневный контроль метрик процесса и эффекта сценариев A–C.

## 2. Пользователи

| Роль | Что смотрит |
|---|---|
| Коммерческий директор (SH-01) | Страница 1 |
| Руководитель логистики (SH-02) | Страницы 1, 2 |
| Менеджер по продавцам (SH-03) | Страница 3 |

## 3. Метрики

| ID | Метрика | Формула | Требование BRD |
|---|---|---|---|
| M-01 | Заказы | `COUNT(DISTINCT order_id)` | BQ-01 |
| M-02 | GMV | `SUM(payment_value)` по заказам `delivered` | BQ-01 |
| M-03 | AOV | M-02 / M-01 | BQ-01 |
| M-04 | Доля опозданий | заказы, где `delivered_customer_date::date > estimated_delivery_date::date` / доставленные с датой | BQ-03, BQ-04 |
| M-05 | Медиана срока этапа | `PERCENTILE_CONT(0.5)` по длительности этапа, дн | BQ-07 |
| M-06 | Средняя оценка | `AVG(review_score)`, последний отзыв по заказу | BQ-03 |
| M-07 | Доля негатива | доля отзывов с `review_score <= 2` | BQ-03, BQ-05 |
| M-08 | Нарушения срока продавцом | заказы, где `delivered_carrier_date > MAX(shipping_limit_date)` / доставленные | BQ-05, сценарий A |

Правила: метрики доставки — только `order_status = 'delivered'` и заполненная дата доставки (DQ-02, DQ-13); длительности этапов — без аномалий порядка дат (DQ-14).

## 4. Страницы

| Страница | Виджеты |
|---|---|
| 1. Обзор | KPI M-01…M-04, M-06; динамика заказов и GMV по месяцам; доля опозданий по месяцам |
| 2. Логистика | Медианы этапов (M-05); карта/таблица доли опозданий по штатам; оценка по дням опоздания |
| 3. Продавцы | Топ продавцов по M-08 и M-07 (от 30 заказов); доля опозданий при нарушении срока и без |

## 5. Фильтры

Период (месяц заказа), штат покупателя, категория товара, продавец.
