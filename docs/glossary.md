# Глоссарий метрик и терминов

Единый словарь проекта: чтобы заказчик, аналитик и разработчик понимали под одним словом одно и то же.
Точные формулы и поля фиксируются в ТЗ (`05_dashboard_spec.md`), здесь — смысл.

## Метрики (KPI из BRD)

| Термин | Расшифровка | Что показывает | Пример вопроса |
|---|---|---|---|
| **GMV** | Gross Merchandise Value | Суммарная стоимость оплаченных заказов за период | Сколько денег прошло через маркетплейс в марте? |
| **AOV** | Average Order Value | Средний чек: GMV / количество заказов | Сколько в среднем тратит покупатель за один заказ? |
| **On-time delivery rate** | Доля доставок вовремя | Доля заказов, доставленных не позже обещанной даты | Как часто мы выполняем обещание по сроку? |
| **Средняя оценка** | Average review score | Средний балл отзывов от 1 до 5 | Насколько покупатели довольны? |
| **Доля негатива** | Negative review rate | Доля отзывов с оценкой 1–2 | Какая часть покупателей недовольна? |
| **Repeat purchase rate** | Доля повторных покупок | Доля покупателей с 2+ заказами | Возвращаются ли к нам люди? |

## Термины анализа

| Термин | Значение |
|---|---|
| **Grain (гранулярность)** | Что означает одна строка таблицы. В `orders` — один заказ, в `order_items` — одна позиция заказа |
| **Первичный ключ (PK)** | Поле или набор полей, уникально определяющий строку |
| **Внешний ключ (FK)** | Поле, ссылающееся на ключ другой таблицы; через него таблицы связываются |
| **JOIN** | Соединение таблиц по ключу |
| **Retention** | Удержание: доля покупателей, вернувшихся за повторной покупкой |
| **Когорта** | Группа покупателей, объединённая общим признаком, например месяцем первой покупки |
| **Data quality (DQ)** | Качество данных: полнота, уникальность, корректность типов |
| **Витрина данных (data mart)** | Подготовленная таблица под конкретную задачу, например под дашборд |
| **Гипотеза** | Проверяемое предположение о причине явления |
| **Операционализация** | Перевод абстрактного понятия в измеримую метрику |

## Бизнес-термины Olist

| Термин | Значение |
|---|---|
| **Продавец (seller)** | Небольшой бизнес, продающий товары через Olist |
| **Обещанная дата доставки** | `order_estimated_delivery_date` — дата, которую покупатель видит при заказе |
| **Перевозчик (carrier)** | Логистический партнёр, доставляющий заказ |
| **BRL** | Бразильский реал, валюта всех сумм в данных |
