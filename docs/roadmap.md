## План SQL-практики

| Неделя | Темы | Применение в проекте |
|---|---|---|
| 1 | CREATE TABLE, типы данных, загрузка CSV, SELECT, WHERE, ORDER BY, LIMIT | Загрузка данных в БД, первые выборки |
| 2 | Агрегатные функции, GROUP BY, HAVING, JOIN | GMV по месяцам, оценки по категориям, проверка DQ |
| 3 | Подзапросы, CTE, CASE, работа с датами |Опоздания доставки, анализ повторных покупок
| 4 | Оконные функции: ROW_NUMBER, RANK, LAG, накопительные суммы | Retention, когорты, первый заказ покупателя, витрины |
