# Дорожная карта проекта

Ежедневный формат: ~30 минут SQL-практики на данных проекта + работа над текущим этапом.

## Логика проекта

Проект повторяет работу бизнес/системного аналитика в компании:

**понять бизнес → понять данные → разложить процесс на этапы (AS-IS) → найти, где и почему возникают проблемы → предложить несколько сценариев (TO-BE) и оценить их → встроить метрики в дашборд → защитить рекомендацию**

| 6 | TO-BE и сценарии | 3 сценария изменений, оценка эффекта, затрат и рисков, рекомендация | Моделирование TO-BE, сценарный анализ | ✅ |

## План SQL-практики

| Неделя | Темы | Применение в проекте |
|---|---|---|
| 1 | CREATE TABLE, типы данных, загрузка CSV, SELECT, WHERE, ORDER BY, LIMIT | Загрузка данных в БД, первые выборки |
| 2 | Агрегатные функции, GROUP BY, HAVING, JOIN, работа с датами | Длительность этапов процесса AS-IS, потери на этапах |
| 3 | Подзапросы, CTE, CASE | Диагностика: опоздания, влияние на оценки и повторные покупки |
| 4 | Оконные функции: ROW_NUMBER, RANK, LAG, накопительные суммы | Расчёт эффекта сценариев, retention, витрины |
