# Olist Analytics Case

Аналитический проект полного цикла на открытых данных бразильского маркетплейса Olist: от бизнес-требований до дашборда и рекомендаций для бизнеса.

> Учебный проект, оформленный как рабочий. Данные реальные (открытый датасет Olist, ~100 тыс. заказов за 2016–2018), заказчик и стейкхолдеры смоделированы.

## Бизнес-задача

Руководство маркетплейса предполагает, что низкие оценки покупателей связаны с задержками доставки, но это не подтверждено данными. Проект отвечает на вопросы:

- как меняются выручка и количество заказов;
- влияет ли опоздание доставки на оценку покупателя;
- в каких регионах и категориях больше всего опозданий;
- какие продавцы дают больше всего негативных отзывов;
- насколько часто покупатели возвращаются.

## Как воспроизвести

1. Скачать датасет [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) и распаковать CSV-файлы в папку `data/raw/`.
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить профилирование данных: `python src/01_profile_data.py`
